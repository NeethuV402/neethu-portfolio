# Neethu Portfolio

## Run the project
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost URL shown in the terminal.

## Customize
Edit `src/main.jsx` for content.
Edit `src/styles.css` for design and colors.

Before deployment, replace the `#` GitHub and LinkedIn links with real profile URLs.
